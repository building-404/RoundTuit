# Reviews Archive

Local archives of code/PR reviews.

Naming: `YYYYMMDD-HHMMSS-slug.md` (flat, timestamped).

Each archived review keeps its full metadata header (Reviewer, Date, Author,
PR URL, Base/Head branch, Head commit, Scope, Method, Outcome). When POSTING a
review to GitHub, strip that header — post findings + recommendation only.

See `conventions/pr-review.md` for the full review standard.
